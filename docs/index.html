Built like a real iOS product

Small surfaces. Strong boundaries.

The feature set is intentionally focused, but the engineering choices are deliberate and demonstrable.

◎

Actor-isolated ingestion

Background parsing and a SwiftData model actor keep long imports away from UI interactions.

▦

Local history with cleanup

Each confirmed import is a batch, making the archive inspectable and deletable as a unit.

◒

State-aware dashboard

Progress is shown for active flights; scheduled departure is shown for upcoming ones.

⌁

Glanceable Live Activity

ActivityKit surfaces the current route and progress without sharing roster persistence with the extension.

A calm architecture

Every boundary has a job.

Inputs become drafts, drafts become reviewed batches, and batches become local views. The system stays understandable because each step has a clear owner.
